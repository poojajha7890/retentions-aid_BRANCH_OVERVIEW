Quick Reference

Common branch, local run, and edit locations.

Switch and compare

git fetch --all
git switch main
git diff --stat main..contabo

Run frontend locally

cd react_app
npm ci
npm start
# CRA: http://localhost:3000

Run API locally

# Requires private flask_app/config.py and Python deps
cd flask_app
conda activate retentions-aid
python app.py
# Debug server: 127.0.0.1:8000

UI: react_app/src/pages and components

Deploy: .github/workflows/main.yml and flask_app/restart.sh
